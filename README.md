# Grupo Escarox - Sitio Web

Sitio web moderno y responsivo para Grupo Escarox, una empresa líder en soluciones industriales y automotrices desde 1991.

## 🚀 Características

- **Diseño Moderno**: Interfaz limpia y profesional con gradientes y animaciones
- **Totalmente Responsivo**: Optimizado para dispositivos móviles, tablets y desktop
- **Navegación Suave**: Scroll suave entre secciones
- **Animaciones**: Efectos visuales atractivos y transiciones fluidas
- **Iconografía**: Iconos modernos de Lucide React
- **Tipografía**: Fuentes Inter y Poppins para mejor legibilidad

## 🛠️ Tecnologías Utilizadas

- **React 18**: Framework principal
- **Vite**: Build tool moderno y rápido
- **Tailwind CSS**: Framework de CSS utility-first
- **React Router**: Navegación entre páginas
- **React Scroll**: Scroll suave entre secciones
- **Lucide React**: Iconos modernos
- **React Typed**: Efecto de escritura animada

## 📦 Instalación

1. **Clonar el repositorio**:
   ```bash
   git clone [url-del-repositorio]
   cd Grupo-Escarox
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Ejecutar en modo desarrollo**:
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador**:
   ```
   http://localhost:3000
   ```

## 🏗️ Scripts Disponibles

- `npm run dev` - Ejecuta el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Previsualiza la build de producción

## 📁 Estructura del Proyecto

```
src/
├── Components/          # Componentes React
│   ├── Navbar.jsx      # Navegación principal
│   ├── GrupoEscarox.jsx # Página de inicio
│   ├── Historia.jsx    # Sección de historia
│   ├── Nosotros.jsx    # Misión, visión y valores
│   ├── Catalogo.jsx    # Catálogo de productos
│   └── Footer.jsx      # Pie de página
├── constants/          # Constantes y configuración
├── Assets/            # Imágenes y recursos
├── App.js             # Componente principal
├── index.js           # Punto de entrada
└── index.css          # Estilos globales
```

## 📱 Secciones del Sitio

1. **Inicio**: Hero section con animaciones y estadísticas
2. **Historia**: Trayectoria de la empresa con timeline
3. **Nosotros**: Misión, visión y valores corporativos
4. **Catálogo**: Productos disponibles con descarga de PDF
